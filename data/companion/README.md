# Approved companion results

`approved-results.json` is intentionally absent until a real tournament export is approved and staged or published. An empty placeholder with a made-up tournament ID would prevent the companion from publishing its real event here.

The static reader is `companion.html`. The versioned connection is configured in `config/companion.json`; integration instructions live in `docs/companion-integration.md`.

Practice fixtures live under `tests/fixtures/`, outside the public site build.
