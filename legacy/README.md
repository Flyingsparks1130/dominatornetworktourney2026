# Inactive data from earlier builds

These files are preserved from previous tournament formats. The current website and importer do not read them, and the static-site build does not publish this directory.

Use `Dominator Tournament/tournament.json` for the official bracket, `Dominator Tournament/control.json` for decisions, and each matchup's `draft.json` for its draft. Generated website data lives in `data/tournament-index.json` and `data/tournament-races/`.

`config/clubs.json` and `config/timeline.json` remain outside this directory because the current club profile and homepage still use them.
